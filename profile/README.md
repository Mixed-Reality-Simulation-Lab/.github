# Mixed Reality Simulation Laboratory
## Fort Lewis College
### An interdisciplinary research laboratory on the Fort Lewis College campus focused on hands-on visualization, mixed-reality simulation, and advanced interdisciplinary STEM research.

## Overview
The lab is an advanced research facility dedicated to the development of modern learning applications and real-time
spatial simulations. The room is equipped with a high-performance motion capture system, 16 mixed-reality headsets, a 
variety of sensors, and a simulation server to power software and control hardware. With undergraduate experience in mind, the lab's
software stack is designed for quick and intuitive application development—thanks to the NOODLES message protocol and 
various custom tools designed for the lab. The lab provides a unified environment where undergraduate students and 
researchers can rapidly prototype, visualize, and evaluate spatial simulations driven by real-time hardware and 
simulation software.
